Robert's RSS Feed

This is a simple GitHub Pages site that publishes a custom RSS feed.

Feed URL: feed.xml

Once published on GitHub Pages, this will become:

https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPO-NAME/feed.xml

What to edit

Edit feed.xml to change the title, description, links, and items.

Edit this index.html page if you want a nicer homepage for your feed.
